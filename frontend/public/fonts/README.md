Self-hosted Latin variable subsets of Newsreader and Source Sans 3 from Google Fonts (fonts.googleapis.com/css2). Both use the SIL Open Font License; the upstream copyright/license notices are included.

Upstreams: https://github.com/google/fonts/tree/main/ofl/newsreader and https://github.com/google/fonts/tree/main/ofl/sourcesans3. No runtime font-service requests.
